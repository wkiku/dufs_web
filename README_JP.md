## 📖 概要

Dufs Web は、機能豊富なファイルサーバーの**Web フロントエンド**です。フレームワークに依存せず、素の JavaScript で実装されています。クラウドストレージのようなファイル管理機能を備え、ファイルのアップロード、ダウンロード、プレビュー、編集などに対応しています。

## ✨ 主な機能

### 🎯 ファイル管理

- **2種類の表示モード**：リスト表示とグリッド表示を切り替えられます
- **並べ替え**：名前、更新日時、サイズで昇順・降順に並べ替えられます
- **一括操作**：複数のファイルを選択して一括削除・ダウンロードできます
- **ドラッグ選択**：リスト表示では、マウスをドラッグして複数項目をすばやく選択できます
- **キーボード操作**：Ctrl／Shift キーとクリックを組み合わせて連続選択できます
- **コンテキストメニュー**：ファイルを右クリックして、ダウンロード、移動、削除、編集などをすばやく実行できます

### 📤 ファイルのアップロード

- **ドラッグ＆ドロップ**：ファイルやフォルダーをページにドロップしてアップロードできます
- **再開に対応**：中断したアップロードを再開できます
- **同時実行数の制御**：同時にアップロードするタスク数を自動で制御します（初期値：3）
- **リアルタイム進捗表示**：フローティングパネルに進捗、速度、残り時間を表示します
- **ファイル検証**：アップロードの再開時にファイル名とサイズを確認します
- **再試行**：失敗したアップロードを手動で再試行できます
- **タスク管理**：完了または失敗したアップロードタスクを整理できます

### 📥 ファイルのダウンロード

- **単一ファイルのダウンロード**：ファイルを個別に直接ダウンロードできます
- **複数ファイルの ZIP ダウンロード**：選択した複数のファイルを ZIP にまとめてダウンロードできます
- **ストリーミングダウンロード**：ReadableStream を使い、進捗をリアルタイムに表示します
- **自動フォールバック**：サイズ上限を超えた場合、個別ダウンロードに自動で切り替えます
- **トークン認証付きダウンロード**：ログインユーザーは安全なトークン認証でダウンロードできます
- **ディレクトリの圧縮**：ディレクトリ全体を ZIP にしてダウンロードできます

### 📝 ファイルのプレビューと編集

- **オンラインエディター**：さまざまなテキスト形式のファイルを編集できます
  - コードファイル：`.js`、`.ts`、`.jsx`、`.tsx`、`.vue`、`.py`、`.java`、`.c`、`.cpp` など
  - 設定ファイル：`.json`、`.yaml`、`.yml`、`.xml`、`.ini`、`.conf`、`.toml` など
  - ドキュメントファイル：`.txt`、`.md`、`.markdown`、`.html`、`.css`、`.scss` など
- **ファイルプレビュー**：さまざまな形式のファイルをブラウザーでプレビューできます
  - 画像：`.jpg`、`.png`、`.gif`、`.bmp`、`.svg`、`.webp` など
  - 動画：`.mp4`、`.mov`、`.avi`、`.wmv`、`.flv`、`.webm` など
  - 音声：`.mp3`、`.ogg`、`.wav`、`.m4a` など
  - ドキュメント：`.pdf` など
- **未保存の変更を確認**：変更を保存せずにページを閉じようとすると、確認メッセージを表示します

### 🔐 ユーザー認証

- **ログイン／ログアウト**：ユーザーのログインとログアウトに対応しています
- **権限制御**：ユーザー権限に応じて機能ボタンの表示・非表示を切り替えます
- **安全なダウンロード**：ログインユーザーのダウンロードにはトークン認証を自動で追加します

### 🌍 多言語対応

- **対応言語**：
  - 🇨🇳 簡体字中国語
  - 🇺🇸 英語
  - 🇯🇵 日本語
- **自動検出**：システム言語を自動検出して適用します
- **設定の保存**：言語設定を localStorage に保存します
- **即時切り替え**：言語を切り替えると画面の表示がすぐに更新されます

### 🎨 使いやすさ

- **レスポンシブデザイン**：デスクトップとモバイル端末に対応しています
- **スクロールバーの自動表示**：コンテンツに応じてスクロールバーを表示・非表示にします
- **パンくずナビゲーション**：現在のパスを分かりやすく表示し、クリックで移動できます
- **トースト通知**：操作結果をリアルタイムに通知します
- **モーダルダイアログ**：確認、入力、通知の操作を統一した画面で行えます
- **ファイル数の表示**：現在のディレクトリ内のファイル数とフォルダー数をリアルタイムに表示します
- **空の状態の案内**：空のフォルダーや検索結果がない場合に案内を表示します

### 🛡️ セキュリティ

- **ファイル名の検証**：パストラバーサル攻撃を防ぎます
  - `/` と `\` のパス区切り文字を禁止
  - `..` によるパストラバーサルを禁止
  - 制御文字を禁止
  - Windows の予約名（CON、PRN、AUX など）を禁止
- **XSS 対策**：ユーザー入力をすべて HTML エンティティにエンコードします
- **ページ離脱時の保護**：未保存の内容や実行中のタスクがある場合、確認メッセージを表示します

## 🚀 クイックスタート

### 必要な環境

- モダンブラウザー（Chrome、Firefox、Edge、Safari など）
- バックエンドサーバー（所定の API エンドポイントが必要です）

### ファイル構成

```
assets/
├── index.html      # メインページ
├── app.js          # メインアプリケーションの処理
├── utils.js        # ユーティリティ関数と定数
├── auth.js         # 認証ユーティリティ
├── i18n.js         # 多言語設定
├── uploader.js     # アップロード管理
├── jszip.min.js    # ZIP ダウンロード用の JSZip ライブラリ
├── base.css        # 基本スタイル
└── components.css  # コンポーネントのスタイル
```

### 組み込み手順

1. **必要なファイルを読み込む**

HTML に CSS と JavaScript を読み込みます。

```html
<link rel="stylesheet" href="assets/base.css">
<link rel="stylesheet" href="assets/components.css">
```

```html
<script src="assets/jszip.min.js"></script>
<script src="assets/i18n.js"></script>
<script src="assets/utils.js"></script>
<script src="assets/auth.js"></script>
<script src="assets/uploader.js"></script>
<script src="assets/app.js"></script>
```

2. **バックエンド API を設定する**

バックエンドには、次の API エンドポイントが必要です。

- `GET /path?json` - ディレクトリの内容を JSON 形式で取得
- `GET /path?zip` - ディレクトリを ZIP 形式でダウンロード
- `GET /path?tokengen` - ダウンロードトークンを生成
- `PUT /path` - ファイルをアップロード／作成
- `DELETE /path` - ファイル／ディレクトリを削除
- `MKCOL /path` - ディレクトリを作成
- `MOVE /path` - ファイルを移動／名前変更（Destination ヘッダーが必要）
- `CHECKAUTH /path` - 認証状態を確認
- `LOGOUT /path` - ログアウト

3. **データ形式**

バックエンドが返す JSON の形式：

```json
{
  "href": "/path/to/dir",
  "uri_prefix": "/",
  "kind": "Index",
  "dir_exists": true,
  "allow_archive": true,
  "allow_upload": true,
  "allow_delete": true,
  "allow_search": true,
  "user": "username",
  "paths": [
    {
      "name": "file.txt",
      "path_type": "File",
      "mtime": 1234567890,
      "size": 1024
    }
  ]
}
```

## 📋 設定

### アップロード設定

```javascript
// 同時にアップロードする最大数
const DUFS_MAX_UPLOADINGS = 3;

// ディレクトリサイズ表示の最大サブパス数
const MAX_SUBPATHS_COUNT = 1000;
```

### 一括ダウンロード設定

```javascript
// まとめてダウンロードするファイルサイズの上限（MB）
const _maxDownloadSize = 200;
```

### 対応ファイル形式

**編集可能な形式**（EDITOR_FORMATS）：

- テキストファイル：`.txt`、`.md`、`.markdown`
- コードファイル：`.js`、`.ts`、`.jsx`、`.tsx`、`.vue`、`.py`、`.java`、`.c`、`.cpp`、`.h`、`.hpp`、`.cs`、`.php`、`.go`、`.rs`、`.swift`、`.kt`、`.rb`
- 設定ファイル：`.json`、`.yaml`、`.yml`、`.xml`、`.html`、`.htm`、`.css`、`.scss`、`.less`、`.ini`、`.conf`、`.cfg`、`.env`、`.toml`、`.sql`
- その他：`.log`、`.csv`、`.gitignore`、`.dockerignore`

**プレビュー可能な形式**（IFRAME_FORMATS）：

- 画像：`.pdf`、`.jpg`、`.jpeg`、`.png`、`.gif`、`.bmp`、`.svg`
- 動画：`.mp4`、`.mov`、`.avi`、`.wmv`、`.flv`、`.webm`
- 音声：`.mp3`、`.ogg`、`.wav`、`.m4a`

## 🎯 使い方

### ファイルのアップロード

1. ツールバーの「アップロード」ボタンをクリックするか、ファイル／フォルダーをページにドラッグ＆ドロップします
2. アップロードパネルが自動で開き、進捗を表示します
3. 一時停止、再試行、キャンセルができます
4. アップロードが中断された場合、次回アクセス時に再開するか確認します

### 一括操作

**リスト表示：**

- チェックボックスをクリックしてファイルを選択
- マウスをドラッグして複数項目を選択
- Ctrl + クリックで選択状態を切り替え
- Shift + クリックで範囲選択

**グリッド表示：**

- ファイルを長押しして選択モードに切り替え
- ファイルをクリックして選択状態を切り替え
- 「選択を終了」をクリックして選択モードを終了

**一括操作：**

- ファイルを選択すると一括操作バーが表示されます
- 「ダウンロード」をクリックして選択したファイルをまとめてダウンロード
- 「削除」をクリックして選択したファイルを一括削除

### ファイルの編集

1. 編集可能なファイルの「編集」ボタンをクリックします
2. エディターで内容を変更します
3. 「保存」ボタンをクリックして変更を保存します
4. ファイルの移動／名前変更や削除にも対応しています

### ファイルのプレビュー

- 画像、動画、音声、PDF などのファイルをクリックするとプレビューできます
- ブラウザー内蔵のビューアーを使用します

### 検索

1. 画面上部の検索ボックスにキーワードを入力します
2. 現在のディレクトリとサブディレクトリを自動で検索します
3. 検索結果はリスト形式で表示されます

## 🔧 API リファレンス

### ユーティリティ関数

**URL 関連：**

- `baseUrl()` - 現在のベース URL を取得
- `newUrl(name)` - 新しいファイル／ディレクトリの URL を作成
- `baseName(url)` - URL からファイル名を取得
- `extName(filename)` - ファイルの拡張子を取得

**フォーマット関連：**

- `formatMtime(mtime)` - 更新日時を整形
- `formatDirSize(size)` - ディレクトリサイズを整形
- `formatFileSize(size)` - ファイルサイズを整形
- `formatDuration(seconds)` - 時間を整形
- `formatSpeed(speed)` - 転送速度を整形

**ファイルアイコン：**

- `getFileIcon(filename, path_type)` - ファイルアイコンの SVG を取得

**検証関連：**

- `validateFileName(filename)` - ファイル名の安全性を検証

### 認証関数

- `fetchWithAuth(url, options)` - 認証付き fetch ラッパー
- `showLogoutModal()` - ログアウト用モーダルを表示
- `hideLogoutModal()` - ログアウト用モーダルを非表示

### 多言語対応

- `t(key, ...args)` - 翻訳関数
- `setLanguage(lang)` - 使用言語を設定
- `loadLanguage()` - 保存された言語設定を読み込む
- `updateTranslations()` - ページ内の翻訳を更新

## 🐛 トラブルシューティング

### 1. アップロードに失敗する

**原因：** ネットワークの問題、またはサーバー側の制限が考えられます。

**対処方法：**

- ネットワーク接続を確認してください
- サーバー設定（ファイルサイズ制限、タイムアウトなど）を確認してください
- もう一度アップロードしてください

### 2. 一括ダウンロードに失敗する

**原因：** ファイルサイズが大きすぎるか、ディレクトリが含まれている可能性があります。

**対処方法：**

- 選択するファイル数を減らしてください
- `_maxDownloadSize` の設定を調整してください
- 個別ダウンロードを使用してください

### 3. エディターでファイルを開けない

**原因：** ファイル形式が未対応か、ファイルサイズが大きすぎる可能性があります。

**対処方法：**

- ファイルの拡張子が `EDITOR_FORMATS` の一覧に含まれているか確認してください
- オンライン編集に適したファイルサイズか確認してください

### 4. 言語を切り替えられない

**原因：** ブラウザーのキャッシュ、または localStorage に問題がある可能性があります。

**対処方法：**

- ブラウザーのキャッシュを削除してください
- localStorage を消去してから再度お試しください
